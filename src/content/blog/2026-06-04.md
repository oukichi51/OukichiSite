## プロジェクト関係者の役割


### 頻出

| 用語 | 一言でいうと | 試験でのポイント |
|---|---|---|
| **利用者・ユーザ** | 使う人 | 要件確認や受入れに関わる |
| **顧客・発注者** | 依頼する側 | システムやサービスを発注する |
| **ベンダ・受注者** | 作る／提供する側 | 開発や運用を請け負う |

### プロジェクト関連

| 用語 | 一言でいうと | 試験でのポイント |
|---|---|---|
| **ステークホルダ** | 利害関係者 | プロジェクトに影響を与える／受ける人や組織 |
| **プロジェクトスポンサ** | 支援する上位者 | 資金・権限・資源を与える |
| **プロジェクトチーム** | 実行する集団 | プロジェクトマネージャとメンバで構成され、作業を進める |
| **プロジェクトマネージャ** | 管理責任者 | 納期・コスト・品質・リスクなどを管理する |
| **プロジェクトメンバ** | 作業担当者 | 実際の作業を行う |
| **PMO(プロジェクトマネジメントオフィス)** | 管理支援組織 | 標準化、助言、進捗管理支援などを行う |

## 作業配分モデル

作業量を人員や期間に割り振るためのモデル

### 基本式

```text
(工数) = (人数) × (期間)
```

### 具体的な問題のメモ

228日で57%の作業が完了。現在の作業も5.5%は終了。あと何日かかるか計算する問題。
まず、全体の日数を求める。
```text
(全体) = 228 ÷ 0.57 = 400(日)
```
今、62.5%の作業が完了しているので、残りの37.5%が終わる期間を求めればいい。
```text
(残りの日数) = 400 × 0.375 = 150(日)
```

## EVM(Earned Value Management)

コストとスケジュールの2つを定量的に管理する進捗管理方法。

### 基本の3要素


| 略語 | 意味 | 説明 |
|---|---|---|
| **PV** | Planned Value | 計画上、現時点までに完了しているはずの作業量・予算 |
| **EV** | Earned Value | 実際に完了した作業の価値・出来高 |
| **AC** | Actual Cost | 実際にかかったコスト |

### 重要な式

```text
SV = EV − PV
```
SVはスケジュール差異。  
0より大きければ予定より進んでおり、0より小さければ予定より遅れている。

```text
CV = EV − AC
```
CVはコスト差異。  
0より大きければ予算内、0より小さければ予算超過である。

```text
SPI = EV ÷ PV
```

SPIはスケジュール効率指数。  
1より大きければ予定より進んでおり、1より小さければ遅れている。

```text
CPI = EV ÷ AC
```

CPIはコスト効率指数。  
1より大きければコスト効率が良く、1より小さければコスト効率が悪い。
